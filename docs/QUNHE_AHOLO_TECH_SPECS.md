# 《特立独行的猪》技术对接规范
## 群核科技 AHOLO (3D空间/场景资产) + GPT6 Astra 智能叙事

---

### 一、群核科技 AHOLO 3D场景与空间接入管线

群核科技在三维室内空间设计、BIM建筑信息模型、数字资产库及具身环境生成方面具有行业领先的积累。本游戏场景（现代化大厂办公室）深度结合群核 AHOLO 的资产与空间生成能力。

#### 1. 资产导出规格 (Coohom / AHOLO to Godot 4)
- **模型格式**：标准 `.glb` / `.gltf` 2.0 格式（嵌入纹理或独立导出）。
- **坐标系转换**：群核默认 Y 轴向上（右手系），与 Godot 4.x 坐标系完全一致。
- **碰撞体自动生成规则 (Godot 命名约定)**：
  - 在群核资产导出或命名时，若在 Mesh 名称后添加后缀 `-col`，Godot 4 导入时会自动生成静态凹凸网格碰撞体（Static Collision）。
  - 若添加后缀 `-colonly`，Godot 会将其作为纯碰撞体而不渲染其表面。
  - 对于可被猪冲撞撞飞的轻量级物体（如椅子、纸箱、咖啡杯），添加 `-rigid` 后缀，Godot 会自动实例化为 `RigidBody3D`。
- **Web 端运行性能优化指标**：
  - **总面数预算**：第一关单屏可视面数控制在 50,000 ~ 80,000 面以内，确保在浏览器端（WebGL 2.0 / WebAssembly）跑满 60fps。
  - **纹理贴图**：使用 1024x1024 或 512x512 尺寸，启用 WebP 格式压缩或基础通道压缩。
  - **光照方案**：采用 Godot 4 Compatibility 渲染模式，群核导出场景可烘焙好 Ambient Occlusion (AO) 贴图或 Lightmap，减少运行时动态实时阴影开销。

### 二、GPT6 Astra 智能叙事与动态职场黑话引擎

#### 1. 架构定位
GPT6 Astra 作为本项目的多模态/大模型职场梗生成大脑，负责：
1. **动态明暗台词生成**：根据玩家猪在关卡里的行为（如拱倒了谁的电脑、在哪个区域叫了一声），动态输出具有时代共鸣的大厂黑话与自嘲毒舌。
2. **NPC 心理防线动态演进**：当猪发出叫声时，NPC根据疲惫度做出不同反应（从“谁在影响我的产出”到“干脆让猪把我电脑拱坏算了，不想加班了”）。

#### 2. Prompt Engineering 规范 (Astra 角色预设)
```text
System Prompt:
你是一位兼具顶级大厂公关话术与资深毒舌打工人双重人格的叙事生成器。
当前游戏：《特立独行的猪：逃离牛马大厦》
角色：
- 明线人格：充满“赋能、闭环、抓手、心智、飞轮、组合拳、拉通对齐”的HR政委式播音腔。
- 暗线人格：一语道破残酷真相、极具网梗自嘲、尖锐讽刺996和内卷的打工猪内心独白。
输入格式：{ "action": "猪用鼻子撞飞了总监的咖啡", "location": "会议室门口" }
输出格式：
{
  "speaker": "对话发出者",
  "surface": "明面正能量/黑话声明",
  "subtext": "暗面毒舌吐槽/内心真实台词"
}
```

#### 3. 本地回退缓存（Offline-first for Web/Steam）
- 为保证 Web 端无延迟畅玩，所有核心主线剧情对话在 `scripts/core/dialogue_manager.gd` 中进行本地结构化存储；
- 在联网且开启 Astra 功能时，异步请求云端扩充台词库并即时无缝接入。

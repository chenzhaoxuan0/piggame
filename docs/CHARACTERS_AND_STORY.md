# 《特立独行的猪：逃离牛马大厦》
## 角色设计规范、故事剧本与职场融梗体系

---

### 一、四大主角人设与视觉规范 (Visual & Character Bible)

本项目核心采用 **2.5D 可爱卡通 / 低多边形轻量风格化 (Low-Poly Stylized)**，以萌感可爱的外表反衬荒诞真实的职场现实。

#### 1. 【特立独行的猪 (The Maverick Pig)】—— MVP阶段唯一可操控主角
- **原型与精神内核**：
  致敬王小波笔下那只“拒绝被骟、拒绝按既定命运生活”的独立生命。在这个现代化CBD的996钢铁牢笼中，它是唯一清醒的“非牛马生物”。
- **角色定位**：觉醒反抗者、摸鱼宗师、秩序破坏者。
- **外观与特征**：
  - **体型**：粉嫩圆润，走起路来小卷尾巴一甩一甩，动作却出奇敏捷。
  - **装饰配饰**：脖子上系着一根半截被咬断的挂绳工牌（写着“实习生·猪猪”）；鼻梁上架着一副帅气的防蓝光黑墨镜；偶尔叼着一根吸管。
  - **技能设定**：
    - **【哼哧猪叫 (Oink)】**：释放反叛声波，惊扰路人、打断同事摸鱼或代码思路、掉落手中物品。
    - **【职场冲撞 (Dash / Boar Charge)】**：低头前冲，撞翻滑轮办公椅、撞翻垃圾桶、冲散打印机纸张、推开半虚掩的安全门。
    - **【敏捷拱食 (Interact / Forage)】**：用鼻子拱翻外卖箱、叼走工牌、喝掉未喝完的奶茶补充体力。
- **关卡主线目标**：
  **逃出办公室大楼**！从第3层开始下潜，一路穿过工位区、透明会议室、总监办公室，最终坐上下行电梯逃向底层出口。

---

#### 2. 【老黄牛 (The Relentless Ox)】—— 规划中角色
- **精神内核**：
  大厂老黄牛、老实人卷王、被严重PUA的技术中坚。
- **外观与特征**：
  - 棕黄牛角上挂着厚重的降噪头戴耳机，眼眶是乌黑浓重的黑眼圈。
  - 身穿深蓝格子衬衫，背后背着塞满3台笔记本电脑的超重瑞士军刀双肩包。
  - 手里死死抱着用青轴敲得劈啪作响的RGB机械键盘。
- **故事目标**：
  **“历经千难万险，回到工位完成工作”**！无论是遭遇停电、消防演练还是猪制造的混乱，牛唯一的执念就是赶在周五晚上23:59前提交周报和修复Bug。
- **技能预设**：
  - **【负重前行】**：无视障碍物阻力，强行推开挡路的隔板或杂物。
  - **【深度加班】**：进入专注状态，对周围一切混乱免疫。

---

#### 3. 【领头羊 (The PowerPoint Sheep)】—— 规划中角色
- **精神内核**：
  “包装大师”、“汇报狂魔”、“向上管理专家”。
- **外观与特征**：
  - 雪白羊毛修剪得像高级沙龙发型，披着定制的浅灰色修身西装小马甲。
  - 羊蹄戴着Apple Watch，手里捏着一支高档激光翻页笔。
  - 说话永远夹杂英文黑话（“Let's sync up on this alignment”）。
- **故事目标**：
  **“一路向阳，直捣顶层进入董事会”**！它的目标不是逃离，也不是在底层干活，而是踩着各部门成果的“闭环”一路坐VIP总裁专梯上到顶楼88层董事会，向CEO进行“顶层战略汇报”。
- **技能预设**：
  - **【概念画饼】**：口吐金光四射的黑话光环，让周围的保安或HR陷入3秒的哲学思考。
  - **【邀功瞬移】**：在别的人物完成任务的瞬间出现在旁边合影留念。

---

#### 4. 【神秘马 (The Enigmatic Horse)】—— 提案库 (供选择)
针对马的角色定位，提供以下三种强共鸣方案：
- **方案A【跑路猎头马 (The Headhunted Stallion)】**：
  - 设定：大厂跳槽专家，手里捏着各路竞品的Offer，在公司里闪转腾挪只为了偷出自己的劳动合同与竞业协议。
- **方案B【拍马屁之马 (The Sycophant Pony)】**：
  - 设定：高管身边的贴心生活秘书，擅长揣摩上意、送咖啡、排座位，在复杂的职场权力斗争中走钢丝。
- **方案C【空降特洛伊木马 (The Trojan Horse)】**：
  - 设定：拿着百万年薪空降的VP，实际连Excel数据透视表都不会做，需要在不露馅的情况下在公司混完第一周试用期。

### 二、明暗双线叙事哲学与融梗语料库

本项目最大的特色在于 **“表面和谐温馨的大厂合规宣传” vs “刺骨扎心而又爆笑的暗面现实”**。

| 场景事件 | 明线宣传 (Corporate Surface) | 暗线真相 (Subtext / Toxic Reality) |
| :--- | :--- | :--- |
| **开局全员广播** | “亲爱的小伙伴们，敏捷共创赋能会即将开始，一起拥抱变化！” | “翻译：今晚全员无偿加班，谁敢按时打卡下班谁就准备进毕业优化名单。” |
| **工位电脑待机** | “以奋斗者为本，每一行代码都在改变世界！” | “改不改变世界我不知道，但我头上的头发确实一行行地消失了。” |
| **捡到P7工牌** | “卓越贡献者专属身份徽章，承载信任与使命。” | “工牌一挂，尊严全下；打卡滴一下，寿命减半年。” |
| **茶水间咖啡机** | “全自动意式研磨咖啡，激发无穷无限创新灵感。” | “苦得像牛马的命，不过是给打工人续命的高纯度合法兴奋剂。” |
| **冲撞领导办公室**| “扁平化沟通，老板的门永远为你敞开！” | “门确实敞开着，但进去提加薪的人基本都没能活着走出来。” |
| **电梯下行逃生** | “感谢您今天的辛勤付出，公司与您共同成长！” | “再见吧这破地方！连猪都不呆的大楼，老子润了！” |

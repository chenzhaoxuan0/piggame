## 1. P0 — Bug 修复

### 1.1 [#8/#9] 进隐藏关卡后「按空格挣脱」提示卡死

**现状（已定位根因）**：`office_level_1.gd` 的 `_on_qte_requested()` 把 `in_qte=true`、`qte_panel.visible=true`、`player.set_control_mode("qte")`。空格连点靠 `pig_controller._unhandled_input()` 在 `control_mode=="qte"` 时发 `qte_tapped` 信号。而赛道入口（绿水管/树洞等，入口按 COURSE_REDESIGN 惯例放在追逐段末段）触发 `_enter_course()` 时无条件 `player.set_control_mode("explore")`——猪被狗咬住的一瞬间跳进水管，QTE 面板还挂着，但控制模式已被改走，空格再也打不满；只能等 `office_level_1._process` 里 `qte_time_remaining` 倒数归零走 `_finish_qte(false)`。与反馈完全吻合。

**修法（采纳反馈 #9 的方案）**：
- `_enter_course()` 开头：`if in_qte: _finish_qte(false)`（按挣脱失败但不惩罚处理——进关本来就离开了狗的追捕范围，直接判「脱险」更合理，二选一在实施时定，倾向判成功脱险：不涨 `_checkpoint_retries`）。
- 同样在 `_exit_course()` 加一道保险（对称场景）。
- `_finish_qte` 内对 `active_course`/farm 侧狗均已销毁的情况做防御（`resolve_qte` 目标失效时静默收尾）。

**测试**：`test_full_journey` 或新增用例：模拟 `in_qte=true` 状态下进关，断言 `in_qte==false`、`qte_panel.visible==false`、控制模式为 explore。

### 1.2 [#3] 马桶搋子（马桶骑士）没有使用方式

**现状**：机制其实存在——`plunger_launcher.gd` 按 `action_shoot`（Q 键）发射，软辅助瞄准 + 击倒 3 只任意狗（巡逻犬 4.5s 眩晕 / 追逐犬 2.2s）即解锁 `plunger_knight`；拾取物、弹药计数 HUD（左上角 🪠 × N）都在。问题纯出在**教学**：唯一的按键提示是军械库位置一条世界标签（`course_03_woodland.gd:597`），散落在赛道里的搋子拾取物（`plunger_prop.gd`）没有任何说明，玩家捡了不知道按 Q。

**修法（2026-11-15 当日已落地，含追加反馈）**：
- `plunger_prop.gd`：拾取世界标签直接写明「按 [Q] 朝恶犬发射！」。
- `plunger_launcher.gd` 弹药计数面板：副标题常驻小字「按 Q 发射」。
- **鼠标发射 + 鼠标瞄向**（追加反馈）：左键同样发射，弹道方向取鼠标指向（相机射线与发射口等高平面求交），键盘 Q 仍按猪头朝向辅助瞄准。
- **搋子可重复拾取**（追加反馈）：拾取点收走后 18s 冷却再生（`respawn_seconds` 可调），掉落补充同款逻辑，弹药永不枯竭。
- **目标可重复击倒**（追加反馈）：巡逻犬 4.5s / 追逐犬 2.2s 眩晕恢复后可再次击倒，计数持续累加（测试钉住第 4 次击倒）。
- 验证可达性：`test_course_03_plunger.gd` 保有「狗源 ≥3」静态断言。

### 3.3 [#1] 羊矮棚除草小游戏 + 除草机成就

### 3.4 [#2] 羊矮棚水池：假地面 → 真水池 + 下水成就

**修法**：

### 3.5 [#4+#5] 马场计时赛 + 记录牌迁到必经之路
**现状**：
- 记录牌 `RecordBoard` 在 `(55,8,-103)`（跑道东北、马场深处），只有一句静态文本「50 米直道 / 春季纪录 · 35 秒」（`farm_grounds.gd:112-115`）；
- `record_breaker`「35 秒新纪录」实际挂在大院赛道 course_04（`race_timer` + `racing_finish_gate` 真实计时），玩家感知上「不是猪跑出来的」；
- 马场跑道是标准 50m 直道体育场（`mountain_environment._large_racetrack()`，一圈约 169m）。

**修法**：
1. **记录牌迁移**：从 `(55,8,-103)` 移到林间捷径出口（`SecretWoodlandPipeExit (27,8,-103.5)`）旁、马场入口到跑道的必经走廊上——猪出林间/进马场第一眼先见牌子再见马。
2. **牌子即启动器**：与记录牌对话弹出选择（复用对话系统）：「开始赛跑 / 离开」。开始后 3-2-1 倒数（复用 `race_timer` 组件，从课程节点挪到 farm 场景可用）、猪在起点门待发、HUD 计时。
3. **两种完成方式两个成就**：
   - `steady_lap`「稳稳一圈」：沿跑道内侧跑完一整圈回到起点，全程不出跑道（跑道外沿判定：出线即重计或失败提示），不要求速度；
   - `checkpoint_chaser`「抄近道也是本事」：按顺序触达全部 4 个象限检查点（拐弯处各一）后回到起点，**允许**穿场内草地抄近道；
   - 冲线显示用时；跑进 35 秒 → `record_breaker` 改挂马场圈速（描述改为「在马场跑道把 35 秒春季纪录甩在身后」），大院 course_04 的终点横幅文案改「大院金牌杯最佳」避免两个 35 秒撞名。
4. 测试：`test_farm_playground` 加计时赛腿——对话启动、两圈模式各自解锁、35s 成就由真实计时驱动。

### 3.7 [#16] 「返回农场」回到上一存档点 + R 键自救
**现状**：设置 → 关卡直达 → 返回农场固定 `reset_at(Vector3(38.0,24.1,52.0))`（`office_level_1.gd:520`，牛耕地）。而 farm 侧早就有连续追踪的检查点：`farm_grounds._checkpoint`（路线 14m 内自动更新，`_on_checkpoint`），追逐失败重试也在用它——「上一个存档点」的概念现成。
**修法**：
- `_select_level_from_settings("farm")`：改为 `reset_at(farm._checkpoint)`（`_checkpoint` 无效时兜底回固定点）；

## 4. P3 — 大工程（先决策再动工）

### 4.1 [#18] NPC 对话前的生活感（牛耕地 / 羊闷闷 / 马跑圈）
**现状**：老牛/小羊/追风全部呆站原地（NPC 静态摆放，仅对话后的技能演出有动画）；`actor_animation.gd` 已有剪辑播放骨架（`play_oneshot`/`has_clip`），Lux3D 角色是带骨骼的绑定模型（`attach_to_bone` 可用）。
**方案**（按性价比排序）：
1. **追风跑圈**（最出效果、改动最大）：给马一条体育场跑道 waypoints 环线，巡跑（gallop 剪辑或程序化步态 bob），猪进入 6m 或发起对话 → 减速停下进入对话；对话后继续跑。难点：交互判定区要跟着马走（交互 Area3D 挂马身上即可）、追逐剧情触发时马要归位。注意 `RESTS["horse"]` 与剧情点的兼容。

### 4.2 [#19] 围栏外可站立 + 缺口 + 出圈成就
**现状**：整个农场是漂浮的梯田假山（`mountain_environment._terrace()`：台地 + 15m 悬崖 + 边界墙），出圈坠落即死（赛道内由 `course_runner._watchdog` 的 kill_y/bounds 重生；农场侧体验就是「卡出去就死了」）。

# 多品类次元跳跃 redesign 设计文档

> 状态：设计已确认（2026-11-10 升级为多品类次元跳跃）。2026-11-11 四关全部实施完成，后三关完成度与娱乐性加固见文末「实施补记」。
> 范围：整个下山地图完全翻新，四条隐藏关卡分别承载四大经典游戏品类，实现真正的玩法与画风双重次元突破。
> 本文档是本次 redesign 的事实源；所有关卡以此标准制作。

## 1. 理解总结（已确认）

- **最高目标**：让玩家笑出来。不仅画风突变，玩法品类也突变！打破单一糖豆人障碍跑的审美疲劳。
- **角色恒定**：一口猪永远作为唯一平涂无题大鹅风格的主角，以滑稽笨拙的肉身“穿越”进不同的经典游戏世界。
- **四大游戏品类分工**：
  1. **关卡一（牛耕地）**：**《糖豆人》/《猫里奥》物理冲关**。基础移动、弹跳板、旋转大锤、假地板塌陷、终点假旗杆。配合老牛【挣脱之力】。
  2. **关卡二（溪流）**：**《我的世界》体素推方块与水流解谜**。慢节奏物理解谜、推泥土方块填河造路、重力沙砸晕恶犬、红石压力板+TNT炸开黑曜石大门，下界传送门出口。配合老牛力量。
  3. **关卡三（林间）**：**《潜龙谍影/魂系》纸箱潜行与破幻迷宫**。巡逻恶犬扇形视锥与警报「！」、可移动隐匿纸箱/草堆、绵羊【洞察之眸】识破幻影石壁与宝箱怪。
  4. **关卡四（大院）**：**《马里奥赛车》极速漂移与世界纪录冲关**。追尾低视角、速度仪表盘、黄色加速带、西瓜皮后抛滑倒恶犬、野马【疾风之步】全力喷火冲线，打破 35 秒世界纪录。
- **机制原则**：所有机制均为非致死幽默演出；失败/失误会带来滑稽效果并复位到就近软检查点。

## 3. 假设（默认值，实施时如不成立需回到设计）

- PC 单机 Godot 4，60fps 目标，每区活跃刚体 ≤ ~50，分区场景切换隔离开销。
- 4 条赛道 × 2-4 分钟，全程约 30-45 分钟；每区 2-3 个软检查点。
- 首发只做主线四区；计时挑战/彩蛋收集后续追加（YAGNI）。
- 不直接搬表情包图片（肖像/版权风险），用文字捏他/音效复刻/场景戏仿。
- Lux3D 现有规则仍生效：先抠主体再图生 3D、资产编号命名回溯提示词条目、落盘 `assets/models/aholo/`。
- 沿用现有 scene test 体系。

## 4. 最终设计

### 4.1 总体架构

每区一个独立主场景，同时只加载一个区：

```
scenes/courses/course_01_ox_field.tscn   # 首个垂直切片
scripts/courses/
  course_runner.gd        # 挂每区根部：软检查点、恶犬压力调度、出口判定
  components/             # 陷阱组件库：每个 = 独立 .tscn + .gd + export 参数
  meme_layer.gd           # 梗演出：标牌/字幕/音效，文本集中在区域配置
```

- **旅程主控**：`scripts/levels/office_level_1.gd` 瘦身为分区切换 + UI + 剧情对话；关卡逻辑下放 CourseRunner。
- **状态流**：GameManager 阶段机沿用，`chase_1..4` 映射 `course_1..4`；伙伴技能门控、铜插销、结局逻辑不变。区域出口 → `complete_stage_chase` → 主控切下一区。
- **复用不动**：pig_controller（冲刺/闪避/挣脱 QTE）、chase_dog（改非致死干扰）、dialogue_manager、pokemon_showdown、Goose 风格 UI 全套。
- **垂直切片范围**：出圈 → 阿牛剧情 → 牛耕地赛道（3-4 个 set-piece）→ 溪流区入口。

### 4.2 陷阱组件库与牛耕地赛道

垂直切片只造 5 个组件，后续区域按需生长；每个独立场景 + export 参数（击飞力度/触发延迟/复位时间）：

| 组件 | 行为 | 梗原型 |
|------|------|--------|
| 弹跳板 | 弹飞 + 挤压拉伸 | 糖豆人弹跳板 |
| 旋转锤 | 节奏旋转，碰者击飞 | 糖豆人旋转大锤 |
| 假地板 | 踩塌掉到下层安全绕路 | 猫里奥假地板 |
| 诱饵终点 | 墙上画的"出口"，真门在旁边 | 兔八哥画隧道 |
| 滚草垛 | 顺坡滚落刚体 | 印第安纳琼斯滚石 |

**核心机制：梗即提示（telegraph）**。陷阱触发前 1-2 秒给出梗信号——懂梗的笑着躲开，不懂的被滑稽击飞（不致死）。梗是可读性层本身，不是装饰。

牛耕地 4 个 set-piece：

1. **问号砖**：顶马里奥式问号砖期待金币 → 掉草垛把猪弹进岔路，toast"鸡汤来咯"。
2. **宫崎英高的微笑**：最宽最平的路踩上去就塌，歪小路才是真路，塌落字幕"宫崎英高的微笑"。
3. **画中门**：侧墙画的发光"出口"是诱人假捷径，撞上去弹回（"我信你个鬼"）；真出口是正前方直行缺口。假门置侧、真路直行，保证主路径可走查。
4. **大锤节奏阵**：三把旋转锤按"退！退！退！"节奏抡，梗音频即通关节拍器；桥两侧加护栏防止击飞出场。

> 实施注：课程出口的世界切换（农场回添 + 猪重置）须延迟到帧末（call_deferred），避免物理帧中途重置被当帧 move_and_slide 覆盖。

### 4.3 数据流与状态

- **软检查点**：每区 2-3 个 Marker3D，经过即注册；击飞超界（低于兜底 Y 面/卡死超时）→ 滑稽传送回最近点，重置体力速度，无死亡计数。看门狗计时器兜底卡缝。
- **恶犬橡皮筋**：狗速随玩家距离自适应，永不淘汰；咬住时已有阿牛技能 → 挣脱 QTE，否则击飞打滚。作用是催促。
- **技能门控递进**：牛耕地（基础物理 + 挣脱教学，阿牛入口授能）→ 溪流（挣脱实战 + 假地板/诱饵）→ 林间（绵绵授识破，假陷阱发光标记）→ 大院（追风授冲刺，终极 gauntlet）。
- **区域配置**：每赛道一个 Resource——检查点、狗橡皮筋参数、梗文本/音效引用、set-piece 触发器。换梗 = 改配置。
- **信号流**：CourseRunner 发 `checkpoint_reached` / `course_completed` / `player_respawned` → 主控切场景、GameManager 记进度、UI toast。QTE 中不响应击飞，切场景重置 QTE。

### 4.4 美术管线

分区画风提案（具体可再调）：

| 区域 | 画风 | 梗土壤 |
|------|------|--------|
| 牛耕地 | 低多边形平涂田园（基准世界） | 马里奥、猫里奥 |
| 溪流 | 像素/体素风 | 我的世界、复古游戏 |
| 林间 | 童话手绘风 | 迪士尼/吉卜力 |
| 大院 | 糖豆人荧光综艺风 | 糖豆人本题 |

- Lux3D 流程：按区风格出 2D 概念图 → 抠主体 → 图生 3D → `assets/models/aholo/<区域>/` → Godot 导入。资产编号加区域段（`ENV_C1_xxx`）。
- **角色不换风格**：猪/伙伴/恶犬保持平涂——角色是穿越进不同世界的游客，画风反差强化喜剧。
- 像素/体素风省面数，有利于刚体预算。

### 4.5 测试与风险

测试：组件单测（力度/延迟/复位）→ 赛道自动化走查（主路径跑通、检查点、出口、无卡死）→ 异常传送看门狗测试 → **真人试玩验收笑点**（垂直切片核心验收，自动化测不了好不好笑）。

| 风险 | 等级 | 缓解 |
|------|------|------|
| 笑点不成立，坑爹变纯坑 | 最高 | 垂直切片先行，牛耕地验证通过才铺其余三区 |
| 热梗过时 / 表情包版权 | 中 | 梗在可替换配置层；只用捏他/复刻/戏仿 |
| 物理混沌卡死 | 中 | 超界看门狗 + 软检查点；每区刚体 ≤50 |
| 4 套画风生产成本 | 中 | 角色不换风格；分区提示词先行，按区批量生成 |
| 范围蔓延 | 中 | 首发只做主线四区；组件按需生长 |

## 7. 实施补记（2026-11-11，后三关完成度加固）

四关骨架此前已通，但 02/03/04 存在占位实现、可绕过谜题与假演出。本次全部加固，并新增**物理实走测试**（`tests/scene/test_course_0X_traversal.gd` + 共用行走器 `course_traversal.gd`）：由猪的点击寻路控制器带真实物理跑完全程，这是关卡"能不能走通"的唯一实机证据。

### 7.0 公共框架

- **技能赛道内临时化**：隐藏关卡进关自动借出所需伙伴技能（GameManager `grant_course_skills`/`clear_course_skills`），出关即还。此前进关直接把牛/羊/马剧情标成"已完成"，主线待办清单被白嫖打勾。
- **加速类拾取一律赛道内生效**：红薯（C2 台阶/宝箱）、黄金红薯（C3 真宝箱）、金星（C4 道具箱）的加速与无敌均为赛道自有状态（截止时间制，出关 `_exit_tree` 立即结算），不叠乘、不随任何墙钟定时器带出关卡。
- **分区氛围**：新组件 `zone_environment.gd` 按区切换世界环境（溪流=明亮体素白天 / 林间=童话迷雾 / 大院=霓虹夜），出关自动还原主世界天空与太阳。纯程序化，不依赖美术线资产。

### 7.1 C2 溪流（谜题防绕过）

- **TNT 防绕过**：TNT 出生点距压力板 6m（需三次推进），压力板只认"基本压在板上"的方块（半径 1.2m）。旧版 2.2m 半径下猪路过板边一步就能引爆出生点的 TNT，谜题等于不存在。
- **压力板永久按下 bug**（防绕过堵上后暴露）：板子碰撞盒与地面齐平，地面被算作永久重叠 occupant，`is_pressed` 一旦为真永不复位——推 TNT 上板会被吞、关卡无解。复位改为只统计板子真正响应的物体。
- **峡谷真守卫**：占位假狗换成实体哨兵（`patrol_guard_dog.gd`）+ 两侧岩肩收窄的峡谷咽喉。重力沙需要 4 次推动：顺瀑布台阶逐级弹落、再向东一推即活埋守卫开路；黏液块飞跃是备选路线。旧版假狗无碰撞不挡路、沙永远砸不到它。
- TNT 引爆补上体素碎块爆炸演出；台阶红薯从装饰变成真拾取（加速+集齐播梗）；出关补播下界传送门梗。

### 7.2 C3 林间（填建破幻迷宫）

- 原后 40% 是空走廊，本设计的"破幻迷宫"不存在。现于 z=-46..-78 建成六道石墙迷宫：之字形实墙 + 一道幻影墙作真通道；幻墙左跨背后藏真宝箱暗室，金光死胡同里钓贪心的是宝箱怪；第二只巡逻狗镇守之字弯。
- **巡逻守卫实体化**：两处红圆柱占位全部换为实体守卫（堵路、咬人=滑稽击飞、可被纸箱俯冲保龄撞晕，晕眩期间视锥停扫）。
- **视锥遮挡检测**：视锥射线检查掩体，树后与墙后真正藏得住猪。
- **纸箱手感**：脱下只绑 E（空格还给跳跃）、脱下后落地可重复穿上（带 1.5s 自动重穿冷却）、俯冲撞击按狗边沿触发只结算一次。
- **填平主路天坑**：原平台接缝在主行进线上留了两处 1-2m 落坑（潜行道-宝箱林、宝箱林-仙径），走进去就掉、重生、再掉的死循环；实走测试抓到后平台改为精确对接。

### 7.3 C4 大院（真竞速）

- **真赛道**：直走廊改为双 S 弯全程（起点直道→右弯→东外道→左弯→中直道→左弯→西外道"氮气隧道"→右弯→终结直道），外侧霓虹护栏封闭，两块内场为开放沙坑（减速 60%，抄近道反而更慢，恶犬不受影响）。
- **真计时**：起跑栏杆物理拦住猪直到 3-2-1-GO，计时从 GO 开始；新增赛道自带 HUD 实时时钟；终点横幅报告**真实用时**——跑进 35s 播"新纪录诞生"，否则播安慰梗。实测标定（`test_course_04_traversal` 机器人，不躲机关每圈吃 3-5 次击飞）：不冲刺 37-43s（必超时）、合理冲刺 33-41s——35s 纪录必须用好【疾风之步】才破，与"凭借疾风之步打破纪录"的设计本意一致。调节旋钮：`course_04_courtyard.gd` 的 `BOOST_SPEED`。
- **西瓜皮修复**：碰撞掩码加恶犬层（旧版永远滑不到狗）、眩晕走 `stun()` 计时（旧版裸写 phase 下一帧就醒）。
- **惩罚机关（全部带梗预警、非致死）**：迎面滚胎、交通锥回旋（纯物理喜剧道具，撞飞不挡路）、泥潭、氮气隧道双扫堂腿（低杆需起跳，也会扫到追击的恶犬）、终结直道霓虹招牌摆锤（门架立柱与护栏齐平，不留卡猪死角——该死角正是实走测试抓出的）。
- **兑现文案**：跳台落地迷你涡轮、金星真无敌（陷阱/弹力柱/泥潭全免疫）、终结直道体力回满+冲刺提示。

### 7.4 验证体系增量

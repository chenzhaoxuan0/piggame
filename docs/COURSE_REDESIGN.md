# 糖豆人式闯关 redesign 设计文档

> 状态：设计已确认（2026-11-09 brainstorming 流程锁定），待实施。
> 范围：整个下山地图完全翻新，四段追逐改造为四条物理喜剧闯关赛道。
> 本文档是本次 redesign 的事实源；实施前需先完成 §6 的文档修订。

## 1. 理解总结（已确认）

- **最高目标**：让玩家笑出来。梗、意想不到、物理滑稽、画风突变都是喜剧手段，难度与公平性为笑点服务。
- **范围**：整个下山地图（含伙伴剧情区、对决区、索道区）围绕闯关玩法完全翻新；剧情骨架保留——出圈 → 伙伴授能 → 四条赛道 → 农场主对决 → 索道结局。
- **玩法**：糖豆人式物理喜剧障碍 + 坑爹反转陷阱（先建立预期再反转）；击飞不致死；恶犬在身后制造催促压力但不即死。
- **梗**：中文互联网梗 + 游戏文化梗两大主力，世界观内生梗（35 秒纪录、金牌执念）粘底；集中在文本/音效/演出层，可配置替换。
- **惊喜**：全部手工编排成一次性 set-piece（传送门式），不做随机生成；重玩价值（计时挑战/彩蛋收集）后续追加。
- **美术**：每区独立画风（有意突破原统一平涂底线），用项目 Lux3D API 分区生成素材；画风突变本身是笑点。

## 2. 决策日志

| # | 决策 | 放弃的选项 | 原因 |
|---|------|-----------|------|
| 1 | 物理喜剧 + 坑爹反转 | AI 对手同场、玩法轮换 | 单人叙事，喜剧优先 |
| 2 | 击飞不致死 | 即死重来、检查点回退 | 治愈调性，被坑也要笑 |
| 3 | 剧情骨架全保留 | 弱化剧情、独立新模式、闯关合集 | 伙伴能力天然变闯关技能 |
| 4 | 互联网梗 + 游戏梗混合 | 纯游戏梗、纯世界观梗 | 可读性 + 情绪共鸣双层 |
| 5 | 手工编排一次性惊喜 | 随机参数、程序生成 | 埋梗精度与演出效果 |
| 6 | 整图完全翻新 | 仅改造四段追逐 | 凸显玩法变革 |
| 7 | 每区独立画风 | 统一平涂、主线统一+破例 | 画风突变即笑点，Lux3D 摊薄成本 |
| 8 | 垂直切片先行（方案 A） | 全图灰盒先行、关卡系统重构 | 4 条手工关卡不值得造编辑器；笑点验证前置 |

## 3. 假设（默认值，实施时如不成立需回到设计）

- PC 单机 Godot 4，60fps 目标，每区活跃刚体 ≤ ~50，分区场景切换隔离开销。
- 4 条赛道 × 2-4 分钟，全程约 30-45 分钟；每区 2-3 个软检查点。
- 首发只做主线四区；计时挑战/彩蛋收集后续追加（YAGNI）。
- 不直接搬表情包图片（肖像/版权风险），用文字捏他/音效复刻/场景戏仿。
- Lux3D 现有规则仍生效：先抠主体再图生 3D、资产编号命名回溯提示词条目、落盘 `assets/models/aholo/`。
- 沿用现有 scene test 体系。

## 4. 最终设计

### 4.1 总体架构

每区一个独立主场景，同时只加载一个区：

```
scenes/courses/course_01_ox_field.tscn   # 首个垂直切片
scripts/courses/
  course_runner.gd        # 挂每区根部：软检查点、恶犬压力调度、出口判定
  components/             # 陷阱组件库：每个 = 独立 .tscn + .gd + export 参数
  meme_layer.gd           # 梗演出：标牌/字幕/音效，文本集中在区域配置
```

- **旅程主控**：`scripts/levels/office_level_1.gd` 瘦身为分区切换 + UI + 剧情对话；关卡逻辑下放 CourseRunner。
- **状态流**：GameManager 阶段机沿用，`chase_1..4` 映射 `course_1..4`；伙伴技能门控、铜插销、结局逻辑不变。区域出口 → `complete_stage_chase` → 主控切下一区。
- **复用不动**：pig_controller（冲刺/闪避/挣脱 QTE）、chase_dog（改非致死干扰）、dialogue_manager、pokemon_showdown、Goose 风格 UI 全套。
- **垂直切片范围**：出圈 → 阿牛剧情 → 牛耕地赛道（3-4 个 set-piece）→ 溪流区入口。

### 4.2 陷阱组件库与牛耕地赛道

垂直切片只造 5 个组件，后续区域按需生长；每个独立场景 + export 参数（击飞力度/触发延迟/复位时间）：

| 组件 | 行为 | 梗原型 |
|------|------|--------|
| 弹跳板 | 弹飞 + 挤压拉伸 | 糖豆人弹跳板 |
| 旋转锤 | 节奏旋转，碰者击飞 | 糖豆人旋转大锤 |
| 假地板 | 踩塌掉到下层安全绕路 | 猫里奥假地板 |
| 诱饵终点 | 墙上画的"出口"，真门在旁边 | 兔八哥画隧道 |
| 滚草垛 | 顺坡滚落刚体 | 印第安纳琼斯滚石 |

**核心机制：梗即提示（telegraph）**。陷阱触发前 1-2 秒给出梗信号——懂梗的笑着躲开，不懂的被滑稽击飞（不致死）。梗是可读性层本身，不是装饰。

牛耕地 4 个 set-piece：

1. **问号砖**：顶马里奥式问号砖期待金币 → 掉草垛把猪弹进岔路，toast"鸡汤来咯"。
2. **宫崎英高的微笑**：最宽最平的路踩上去就塌，歪小路才是真路，塌落字幕"宫崎英高的微笑"。
3. **画中门**：侧墙画的发光"出口"是诱人假捷径，撞上去弹回（"我信你个鬼"）；真出口是正前方直行缺口。假门置侧、真路直行，保证主路径可走查。
4. **大锤节奏阵**：三把旋转锤按"退！退！退！"节奏抡，梗音频即通关节拍器；桥两侧加护栏防止击飞出场。

> 实施注：课程出口的世界切换（农场回添 + 猪重置）须延迟到帧末（call_deferred），避免物理帧中途重置被当帧 move_and_slide 覆盖。

### 4.3 数据流与状态

- **软检查点**：每区 2-3 个 Marker3D，经过即注册；击飞超界（低于兜底 Y 面/卡死超时）→ 滑稽传送回最近点，重置体力速度，无死亡计数。看门狗计时器兜底卡缝。
- **恶犬橡皮筋**：狗速随玩家距离自适应，永不淘汰；咬住时已有阿牛技能 → 挣脱 QTE，否则击飞打滚。作用是催促。
- **技能门控递进**：牛耕地（基础物理 + 挣脱教学，阿牛入口授能）→ 溪流（挣脱实战 + 假地板/诱饵）→ 林间（绵绵授识破，假陷阱发光标记）→ 大院（追风授冲刺，终极 gauntlet）。
- **区域配置**：每赛道一个 Resource——检查点、狗橡皮筋参数、梗文本/音效引用、set-piece 触发器。换梗 = 改配置。
- **信号流**：CourseRunner 发 `checkpoint_reached` / `course_completed` / `player_respawned` → 主控切场景、GameManager 记进度、UI toast。QTE 中不响应击飞，切场景重置 QTE。

### 4.4 美术管线

分区画风提案（具体可再调）：

| 区域 | 画风 | 梗土壤 |
|------|------|--------|
| 牛耕地 | 低多边形平涂田园（基准世界） | 马里奥、猫里奥 |
| 溪流 | 像素/体素风 | 我的世界、复古游戏 |
| 林间 | 童话手绘风 | 迪士尼/吉卜力 |
| 大院 | 糖豆人荧光综艺风 | 糖豆人本题 |

- Lux3D 流程：按区风格出 2D 概念图 → 抠主体 → 图生 3D → `assets/models/aholo/<区域>/` → Godot 导入。资产编号加区域段（`ENV_C1_xxx`）。
- **角色不换风格**：猪/伙伴/恶犬保持平涂——角色是穿越进不同世界的游客，画风反差强化喜剧。
- 像素/体素风省面数，有利于刚体预算。

### 4.5 测试与风险

测试：组件单测（力度/延迟/复位）→ 赛道自动化走查（主路径跑通、检查点、出口、无卡死）→ 异常传送看门狗测试 → **真人试玩验收笑点**（垂直切片核心验收，自动化测不了好不好笑）。

| 风险 | 等级 | 缓解 |
|------|------|------|
| 笑点不成立，坑爹变纯坑 | 最高 | 垂直切片先行，牛耕地验证通过才铺其余三区 |
| 热梗过时 / 表情包版权 | 中 | 梗在可替换配置层；只用捏他/复刻/戏仿 |
| 物理混沌卡死 | 中 | 超界看门狗 + 软检查点；每区刚体 ≤50 |
| 4 套画风生产成本 | 中 | 角色不换风格；分区提示词先行，按区批量生成 |
| 范围蔓延 | 中 | 首发只做主线四区；组件按需生长 |

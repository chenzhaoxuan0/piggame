# 《一口猪在金牌农场》游戏设计白皮书 (GDD v1.1.0 - 英雄之旅与向上攀登箱庭版)

---

## 1. 核心概述与叙事母题 (Executive Summary & Vision)

- **游戏名称**：《一口猪在金牌农场》 (A Pig in the Golden Farm)
- **体裁与定位**：2.5D 田园围城哲学寓言 × 英雄之旅深度叙事冒险。
- **空间叙事原则**：
  **“悬崖在下方，猪自下而上突围进发”**！
  在 2.5D Isometric 视角下，屏幕近景/下方为万丈深渊绝壁，老岩羊从崖底轻巧跃上残墙；猪从下方的悬崖猪舍出发，一路向屏幕上方突破攀登，穿过耕地泥垄、羊舍草垛、环形跑道与红砖钟楼，最终在最上方的后山绝顶乘索道木吊厢飞向广阔原野。
- **叙事核心原则**：
  **多视角围城互助 + 严谨的英雄之旅十二阶段展开**！
  虽然构建了“A动物羡慕B动物，B动物在它的视角也羡慕/心疼A动物”的围城网络，但**每一个角色的具体故事线，都必须完整按照约瑟夫·坎贝尔《千面英雄》“英雄之旅”十二阶段严格铺陈**，具备从平凡世界、冒险召唤、跨越边界、深渊试炼、生死考验到携灵药重生的完整起承转合！

## 2. 英雄之旅十二阶段与箱庭空间映射

| 阶段 | 戏剧弧光 | 箱庭空间位置 (自下而上) | 核心事件与简短真理 |
| :--- | :--- | :--- | :--- |
| **阶段 1：平凡世界** | 猪舍晨风，冷眼看抢食 | 屏幕最下方：悬崖边残破猪舍 | 猪嚼干麦穗看崖下云雾，不屑争抢添加剂甜料 |
| **阶段 2：冒险召唤** | 绝壁飞跃，引路人登场 | 悬崖边缘石残墙 | 老岩羊从下方绝壁跳上来：“金牌是给死肉戴的” |
| **阶段 3：拒斥召唤** | 深渊荒野的恐惧与内耗 | 悬崖猪舍泥坑 | 离开有温饱的猪圈意味着直面严酷天险，猪曾迟疑 |
| **阶段 4：遇见导师** | 获赠生锈插销与野性启示 | 悬崖边老岩羊石台 | 老岩羊踢过铜插销：“世上最惨的是习惯被骟的生活” |
| **阶段 5：跨越第一道边界** | 撞烂门栓，踏出安全区 | 猪圈北面厚重木门栓 | 猪昂首顶碎门栓，正式向上迈入戒备森严的大院 |
| **阶段 6：考验、盟友与敌人** | 穿越三大作业区解密点化 | 大院中央泥垄、草垛与赛道 | 顶飞阿牛的犁尖卡石、守护绵绵的柔软云彩毛、咬断追风打转的黑皮眼罩 |
| **阶段 7：接近最深洞穴** | 潜入庄园核心控制枢纽 | 大院中央高耸红砖钟楼底层 | 必须切断全区高压总电闸，解除索道锁定 |
| **阶段 8：严峻生死考验** | 困入捕兽钢网，威逼利诱 | 钟楼顶层配电房前 | 老张递来纯金项圈：“做模范种猪，否则明早剔骨” |
| **阶段 9：夺取真理之剑** | 铁拱嘴借力撞断高压电闸 | 钟楼高压电闸箱 | 轰！全庄探照灯与喧嚣熄灭，浩瀚星空与银河涌现 |
| **阶段 10：返回之路** | 全员觉醒掩护猪向上突围 | 中央石道至后山石阶 | 阿牛抵网、追风踏门、绵绵羊群堵路，杀出血路 |
| **阶段 11：灵魂蜕变与复活** | 索道崖口神性对视度化老张 | 屏幕最上方：后山索道崖口 | 交付《自流引水图》：“铜铃虽响，山风更大”，老张扔掉铜铃 |
| **阶段 12：携灵药归来** | 撞入插销，木缆车滑入旷野 | 悬挂于万丈绝壁的木吊厢 | 飞向漫无边际的金黄麦浪与自由群山，围城心锁破碎 |

## 3. 操控与交互范式

- **Point & Click / Tap to Move（点击移动）**：
  - 鼠标左键点击草地/泥土地，或手机触屏轻触，地面泛起淡金色麦穗光圈，猪自下而上稳健小碎步移动；
  - 点击动物或物体自动走近，触发简短有力的真理对话。
- **环境物理推移 (Untitled Goose Game 质感)**：
  - 走动与冲撞过程中与牛奶罐、水桶、干草块、木栅栏发生真实物理碰撞，富含乡村趣味。

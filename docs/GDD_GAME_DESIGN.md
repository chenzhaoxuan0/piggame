# 《特立独行的猪》游戏设计白皮书 (GDD v1.0.0 - 英雄之旅史诗长篇版)

---

## 1. 核心概述与叙事母题 (Executive Summary & Epic Fable)

- **游戏名称**：《特立独行的猪》 (A Maverick Pig: The Animal Farm Odyssey)
- **体裁与定位**：2.5D 现代田园哲学寓言 × 沉浸式叙事探索冒险游戏。
- **叙事骨架**：**完整采用约瑟夫·坎贝尔《千面英雄》“英雄之旅” (The Hero's Journey) 十二阶段古典叙事弧光**。
- **哲学内核**：
  - 致敬王小波《一只特立独行的猪》的独立灵魂；
  - 承袭乔治·奥威尔《动物农场》的寓言深度与反讽力量；
  - 注入温厚成熟的正向救赎力量：主角不是愤世嫉俗的毁灭者，而是唤醒同伴、渡己渡人的生命领航者。
- **核心情感诉求**：**“这简直就是我！”**
  让每一个在现代流水线与繁复规训中疲惫焦虑的打工人，在体验这场跨越平凡世界、深入深渊、最终携灵药归来的史诗之旅后，重拾坚守自我、从容体面生活的无限勇气。

## 2. 英雄之旅十二阶段在游戏中的关卡与机制映射

```
【第一幕：启程 (Departure)】
阶段 1：平凡世界 (谷仓屋顶听雁鸣，看晨光破晓)
阶段 2：冒险召唤 (暴雨夜潜入总控室，发现司庆淘汰烤猪密档)
阶段 3：拒斥召唤 (面对无垠荒野与严酷风雪的内心退缩与迷茫)
阶段 4：遇见导师 (后山老岩羊白须的点化，获赠生锈的索道插销)
阶段 5：跨越第一道边界 (拒绝领槽称重，猪头撞碎猪圈木栓踏入大院)

【第二幕：启蒙与试炼 (Initiation)】
阶段 6：考验、盟友与敌人 (大院三重作业区解密与救赎)
   ├─ 试炼 1：黑土泥潭 ➔ 坚硬猪鼻顶飞卡石，解开老黄牛阿牛的沉重犁枷
   ├─ 试炼 2：羊圈阴影 ➔ 拱送鲜甜胡萝卜，守护小绵羊绵绵如云朵般柔弱的天性
   └─ 试炼 3：封闭环形跑道 ➔ 撞破赛道围栏，咬断烈马追风被蒙蔽的眼罩
阶段 7：接近最深洞穴 (潜入戒备森严的中央红砖钟楼)
阶段 8：严峻生死考验 (落入捕兽大网！面临金项圈编制诱惑 vs 屠宰剔骨威胁)
阶段 9：夺取真理之剑 (铁嘴撞断全庄高压总电闸，刺眼探照灯熄灭，银河繁星涌现)

【第三幕：归途与重生 (Return)】
阶段 10：返回之路 (牛马羊合力筑起血肉长廊，全员大突围掩护猪奔向后山)
阶段 11：灵魂蜕变与复活 (索道崖口从容对视，交付全套引水图，度化管家老张摘下铜铃)
阶段 12：携灵药归来 (木质缆车下行滑向万顷麦浪与自由原野，农庄虽在但规训之锁已碎)
```

## 3. 核心操控与物理交互 (Point & Click + Environmental Physics)

- **沉浸式点击移动 (Point & Click / Tap to Move)**：
  - 无论是 PC 端鼠标点击，还是手机/平板触屏轻触，均以地面金色麦穗光圈为指引，四蹄轻快沉稳走位。
  - 点击 NPC（牛、羊、马、犬）或关键机关（木栓、石头、眼罩、电闸、索道插销），自动走近并触发带有《极乐迪斯科》文学质感的多分支哲思对话。
- **环境物理推移 (Untitled Goose Game 质感)**：
  - 走动过程中与场景中的物理刚体（木水桶、铁牛奶罐、干草捆、木栅栏）发生真实自然的物理碰撞，可碰翻水桶、撞歪围栏，充满田园生活野趣。

## 4. 视听艺术设计 (Audiovisual Direction)

- **场景构筑**：
  - 结合群核科技 AHOLO 的高精度乡村木结构建筑、谷仓、农田水渠、环形跑道与高耸钟楼；
  - 昼夜与光影流转：从清晨薄雾、暴雨雷鸣、黄昏落日熔金，到电闸短路后震撼人心的浩瀚银河星海。
- **配乐风格**：
  - 从开局农庄广播冷硬机械的管乐与铁桶声；
  - 逐渐转变为灵动清脆的木吉他指弹、辽阔激昂的苏格兰风笛、以及充满史诗感的大提琴弦乐重奏。

# Aholo Lux3D 3D 资产生成实操指南与验收标准 (Lux3D Pipeline SOP)

> **文档定位**：为本项目面向 **Aholo Lux3D** 的 3D 生成工作流提供从“提示词/参考图输入”到“网格导出”、“Blender/Godot 检查优化”以及“入引擎验证”的全流程标准作业程序 (SOP)。

## 二、Image-to-3D 预处理黄金规范 (Pre-generation Rules)

若采用“图生 3D”模式，输入的 2D 参考图必须满足：
1. **纯白或中性浅灰单色背景**：严禁带任何地面投影、杂草泥土或背景风景；
2. **正交/等距 3/4 视角 (Orthographic / 45° Isometric)**：确保能同时看清前侧顶三面的几何厚度；
3. **无穿插悬空结构**：例如索道缆绳不要做成随风飘扬的细线，应做成实心有厚度的硬质件；
4. **轮廓闭合**：物体边缘高对比度，无半透明或羽化边缘。

## 三、Aholo Lux3D 导出与入库规范

### 3.1 导出格式与命名标准
- **优先导出格式**：`.glb` (二进制 glTF 2.0，Godot 原生支持且内嵌贴图与材质)。
- **备选格式**：`.obj` + `.mtl` + 独立贴图文件（需在 Blender 中打包为 glTF）。
- **文件存放路径规范**：
  ```text
  assets/
  ├── art_references/props/       # 原始 2D 概念参考图 (PNG)
  └── models/aholo/
      ├── prop_cablecar/
      │   ├── raw/                # Lux3D 原始导出的模型
      │   │   └── cablecar_lux3d_raw.glb
      │   ├── cablecar.glb        # 经过修整、尺寸归一化的最终模型
      │   └── cablecar_preview.png # 渲染效果图/验收证明截图
      ├── prop_irongate/
      └── char_pig/
  ```

## 四、Godot 4 引擎入库四步检查清单 (Quality Gate)

所有由 Lux3D 生成并准备集成到 Godot 的资产，必须严格执行以下四步检查：

### 1. 轴向与原点规范 (Pivot & Orientation)
- **轴向标准**：遵循 Godot 标准——**Y 轴朝上 (Y-Up)**，物体正方向朝向 **-Z**。
- **原点基准 (Pivot)**：
  - 地面静止物体（如铁门、顽石、标牌）：**原点必须位于底部底面中心 (`y=0`)**，方便直接对齐地面；
  - 悬挂物体（如索道吊厢）：**原点位于顶部滑轮与钢缆接触点**，便于程序绑定滑索动画；
  - 角色（猪、NPC）：**原点位于四蹄触地平面的中心点**。

### 2. 比例与包围盒核对 (Scale & Dimensions)
导入 Godot 后，先在三维视口中与白模放置对比：
- **索道木吊厢**：宽约 `2.2m`，长约 `2.8m`，高约 `2.6m`（可容纳一只小猪进入）；
- **后山大铁闸门**：跨度 `4.5m`，高度 `3.2m`，确保横向封死通行路线；
- **生锈铜插销**：长度约 `0.35m`，插在猪嘴或索道凹槽中清晰可见。

### 3. 几何面数与拓扑检查 (Topology & Polycount)
- 道具类资产建议三角面数控制在 **1,500 ~ 8,000 Tris**；
- 角色类资产建议控制在 **3,000 ~ 15,000 Tris**；
- 检查是否存在非流形几何（Non-manifold）、重叠重面或破面缝隙；如有，在 Blender 中按 `M -> By Distance` 合并多余顶点。

### 4. 碰撞体命名后缀快速自动化 (Godot Asset Import Suffixes)
利用 Godot 官方的导入命名规则（参考 [G3]）：
- 若希望模型自动生成凸包碰撞体，将碰撞网格节点命名添加 `-convcol`；
- 若希望模型使用极简盒状碰撞体，添加 `-colonly`；
- 索道吊厢等内部允许进入的物体，建议在 Godot 场景中手动配置组合 `CollisionShape3D`，防止复杂网格碰撞消耗性能。

## 五、首件样件突击实操卡 (First Sample Protocol)

按照全流程生产计划，当主分支白模实机通关（G0 门槛）且用户确认风格（S0 门槛）后：
1. **立即首选【PROP_01：后山悬崖木质索道站与吊厢】作为全项目首个验证样件 (Sample M0)**；
2. 在 Aholo Lux3D 中生成并下载原始 `.glb`；
3. 检查材质、法线与尺寸，导入 Godot 白模场景挂载点 `CableCarMount`；
4. 截取实机运行画面发给用户确认——一旦首件通过，后续资产即可全面流水线生成！

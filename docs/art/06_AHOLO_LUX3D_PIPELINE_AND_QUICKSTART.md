# Aholo Lux3D 3D 资产生成实操指南与验收标准 (Untitled Goose Game 风格 SOP)

> **文档定位**：为本项目面向 **Aholo Lux3D** 的 3D 生成工作流提供从“提示词/参考图输入”到“网格导出”、“Blender/Godot 检查优化”以及“入引擎验证”的全流程标准作业程序 (SOP)。全面对标 **《无题大鹅模拟》(Untitled Goose Game)** 极简平涂低多边形风格。

---

## 一、为什么《无题大鹅》风格是 Aholo Lux3D 的最大生产红利？

传统的写实/重度手绘风格在 AI 3D 生成时经常面临两大致命痛点：
1. **写实毛发与法线易产生大量破面和高频噪点碎面**；
2. **AI 生成的贴图 UV 容易拉伸、接缝错位、出现脏污烘焙阴影**。

而对标 **《无题大鹅模拟》** 风格具有降维打击般的生产优势：
- **极简大色块 (Flat Color Blocking)**：几何结构清晰分明，AI 3D 重建时的法线极其平滑整洁；
- **材质极易修整**：哪怕 AI 导出的贴图略有瑕疵，在 Godot 或 Blender 中直接使用纯色平涂材质（或一张 256x256 调色板贴图）赋予 `StandardMaterial3D`，**2 分钟即可完成一件资产的翻新与修整**；
- **引擎零性能负担**：面数控制在 1,000~5,000 三角面，Godot Compatibility 渲染器轻松 60 FPS 满帧。

## 三、Image-to-3D 预处理黄金规范

若采用“图生 3D”模式，输入的 2D 参考图必须满足：
1. **纯白单色背景 (`#FFFFFF`)**：严禁带任何地面投影、杂草泥土或复杂背板；
2. **正交/等距 3/4 视角 (Orthographic / 45° Isometric)**：确保能同时看清前侧顶三面的几何厚度；
3. **无穿插悬空结构**：例如索道缆绳做成实心有厚度的硬质件；
4. **纯平色块，无真实光影干扰**：让 3D 重建模型专注还原几何形体。

## 四、Godot 4 引擎入库与材质配置标准 (Godot Setup)

所有由 Lux3D 生成并准备集成到 Godot 的资产，按以下规范配置：

### 1. 材质着色器标准配置 (Toon / Flat Shading)
在 Godot 4 材质检查器中设置：
- `Shading -> Diffuse Mode`: **Toon** (卡通平涂漫反射) 或 **Lambert**；
- `Shading -> Specular Mode`: **Disabled** (关闭高光) 或 **Toon**；
- `Albedo`: 使用平涂纯色（或绑定低分辨率调色板贴图），`Roughness` 设为 `0.9 ~ 1.0` (完全哑光)；
- 彻底**禁用** Normal Map (法线贴图) 与 Height Map，呈现纯粹的《无题大鹅》简约美感。

### 2. 轴向与原点规范 (Pivot & Orientation)
- **轴向标准**：遵循 Godot 标准——**Y 轴朝上 (Y-Up)**，物体正方向朝向 **-Z**。
- **原点基准 (Pivot)**：
  - 地面静止物体（如铁门、顽石、标牌）：**原点位于底部底面中心 (`y=0`)**；
  - 悬挂物体（如索道吊厢）：**原点位于顶部滑轮与钢缆接触点**；
  - 角色（猪、NPC）：**原点位于四蹄触地平面的中心点**。

### 3. 比例与包围盒核对 (Scale & Dimensions)
- **索道木吊厢**：宽约 `2.2m`，长约 `2.8m`，高约 `2.6m`（可容纳一只小猪进入）；
- **后山大铁闸门**：跨度 `4.5m`，高度 `3.2m`，横向封死通行路线；
- **生锈红铜插销**：长度约 `0.35m`，插在猪嘴或索道凹槽中清晰可见。

## 五、首件样件突击实操卡 (First Sample Protocol)

当主分支白模实机通关（G0 门槛）且用户确认风格（S0 门槛）后：
1. **立即首选【PROP_01：后山悬崖木质索道站与吊厢】作为全项目首个验证样件 (Sample M0)**；
2. 在 Aholo Lux3D 中输入 `03` 文档中的索道吊厢 Prompt，生成并下载原始 `.glb`；
3. 将材质设置为 Toon 哑光色块，导入 Godot 白模场景挂载点 `CableCarMount`；
4. 截取实机运行画面向用户交付——首件验证通过后，全场其余模型即可批量快速生成！
